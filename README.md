# 个人互联网创业手册

> 从一个想法，到一个能收费、能交付、能合规维护的互联网产品。

这是一套面向个人创业者、独立开发者、设计师和小团队的中文 Obsidian 知识库。

它从经营者视角整理互联网创业的完整链路：需求验证、产品开发、公司与经营主体、支付订阅、法律合规、AI 产品、增长运营、财务税务，以及从想法到上线的实战项目。

本手册尤其关注：

- 中国与国际市场的差异；
- 个人经营与公司经营的边界；
- 中国个人非经营性网站的商业化风险；
- 独立站电商、设计/咨询等契约服务；
- 广告、赞助和联盟营销变现；
- 公司注册后真正需要承担的年度维护成本。

## 实战项目

[`09-实战项目`](09-实战项目/项目总览.md) 提供一条贯穿全库的实践路径：

```text
想法与约束
  → 问题验证
  → MVP 与定价
  → 主体与支付决策
  → 产品与技术设计
  → 合规与上线检查
  → 发布与首批用户
  → 经营仪表盘
  → 复盘与迭代
```

目标不是“读完所有笔记”，而是形成一个真实、可收费、可维护的经营闭环。

## 内容维护原则

- 将法规、平台规则、费用和税率标记为“待核验”。
- 优先引用主管机关和服务商官方页面。
- 区分事实、判断和行动。
- 重要选择使用决策记录，不只保留在聊天或日记中。
- 业务地区、用户、主体或功能变化时，重新进行合规和税务评估。

官方入口汇总：[官方核验入口](11-资源与更新/官方核验入口.md)。

## 重要声明

本仓库用于创业教育、研究和经营决策整理，不构成法律、税务、会计、投资或其他专业意见。

互联网法规、公司费用、支付平台政策和税务规则会持续变化。实际经营前，请根据经营者所在地、公司注册地、用户所在地、服务器和数据位置、产品类别及交易方式，向主管机关和具备资质的专业人士核验。
