# 中国个人非经营网站商业边界

> 这里的“绿、黄、红”表示对**个人非经营性备案网站**的适配程度，不代表对所有主体的最终合法性结论。

## 最关键的三轴模型

### 轴一：互联网信息服务与 ICP

现行《互联网信息服务管理办法》将非经营性互联网信息服务定义为无偿提供具有公开性、共享性的信息，并规定非经营性互联网信息服务提供者不得从事有偿服务。官方原文：

- [互联网信息服务管理办法](https://www.samr.gov.cn/zw/zfxxgk/fdzdgknr/bgt/art/2023/art_483f0dd8eb1b4dc5961e4e008bd4a083.html)
- [非经营性互联网信息服务备案管理办法](https://www.miit.gov.cn/gyhxxhb/jgsj/cyzcyfgs/bmgz/xxtxl/art/2024/art_84a0cfa0ebd049bbbe751dca9a008e56.html)

个人 ICP 备案表示主办者以个人身份提供申报范围内的非经营性信息服务。它不是市场主体登记，也不是在线交易、付费会员或接单经营的许可。

### 轴二：市场主体登记

《电子商务法》将通过自建网站销售商品或提供服务的自然人、法人和非法人组织纳入电子商务经营者范围，原则上要求市场主体登记，但对自产农副产品、家庭手工业产品、依法无须许可的便民劳务和零星小额交易等设有例外。

2025 年修正的《网络交易监督管理办法》进一步列举部分便民劳务，并规定个人网络交易年交易额累计不超过 10 万元的零星小额交易可不登记；需要行政许可的除外。官方原文：

- [中华人民共和国电子商务法](https://www.samr.gov.cn/zfjcj/tzgg/art/2023/art_d337c3291e8b40459ca03dea54395856.html)
- [网络交易监督管理办法](https://www.samr.gov.cn/zw/zfxxgk/fdzdgknr/fgs/art/2025/art_4b47c79b8d994a42bba4835997688faa.html)

**注意：**“无需市场主体登记”不等于“个人非经营性备案网站可以站内收费”。这两套制度回答的是不同问题。

### 轴三：税务与具体经营义务

即使属于免于市场主体登记的例外，仍可能需要：

- 依法申报纳税；
- 公示经营者或“依法无需登记”的信息；
- 履行消费者权益、商品质量、广告、知识产权和个人信息义务；
- 对特定商品或服务取得许可；
- 遵守支付机构和接入商规则。

## 场景边界表

| 场景 | 个人非经营备案适配 | 原因与建议 |
|---|---|---|
| 免费博客、技术笔记、个人简历 | 🟢 较适配 | 无交易、无付费内容、无商业推广时最接近非经营性信息服务 |
| 作品集，仅展示作品和个人联系方式 | 🟢/🟡 | 纯展示风险较低；若突出报价、预约、促销和长期接单，商业属性上升 |
| 免费开源工具，无广告、无付费功能 | 🟢 | 仍需注意数据、内容、许可证和备案内容一致 |
| 自愿赞赏且无任何对应权益 | 🟡 | 是否构成经营或有偿服务取决于实际设计、频率和宣传；先向接入商、属地管局核验 |
| 跳转第三方平台购买商品或服务 | 🟡 | 站点可能同时构成宣传或广告；平台交易不自动消除本站的备案、广告和税务问题 |
| 展示设计服务、报价范围、询价表单 | 🟡/🔴 | 单纯作品展示与持续招揽业务之间没有一条统一安全线；反复接单更接近网络经营 |
| 广告联盟、横幅广告、直接赞助 | 🟡/🔴 | 广告收入带来明显商业属性；广告法义务与 ICP 备案适配需分别核验 |
| 文章中放佣金链接或付费测评 | 🟡/🔴 | 可能构成互联网广告，需要显著可识别并留档；大量、持续变现不宜继续按纯个人展示站理解 |
| 站内购物车、订单、在线支付 | 🔴 | 不适合个人非经营性网站；应迁移经营主体和备案，再判断是否需要额外许可 |
| 付费下载、会员、课程、订阅、付费咨询预约 | 🔴 | 直接有偿提供信息或服务，和个人非经营性站点定位明显冲突 |
| 为第三方商家提供入驻、撮合、交易 | 🔴 | 已接近平台业务，可能涉及更重的主体、平台和增值电信许可义务 |

## 广告的特殊说明

现行规则没有给出“个人备案网站出现一条广告就必然属于经营性 ICP”的简单公式。广告收入、广告内容和网站服务性质要分别判断：

1. **广告活动本身**受《广告法》和《互联网广告管理办法》约束。
2. **网站备案适配**需看网站实际内容是否仍与个人非经营性备案一致。
3. **持续经营与收入**还会触发市场主体和税务判断。

因此，不应使用“只要不在站内收用户的钱就一定安全”的判断。

## 设计接单的特殊说明

《网络交易监督管理办法》列举的便民劳务主要是保洁、洗涤、缝纫、理发、搬家、配钥匙、维修等。设计、咨询、开发、代运营不当然属于这些例子。偶发交易是否属于零星小额，要结合累计交易额、持续宣传、业务组织程度和当地口径判断。

## 决策前必须询问

向接入商和属地通信管理局描述**真实功能**，而不是只问“能不能变现”：

- 网站是否展示服务价格或接受询价？
- 是否有广告联盟、赞助或佣金链接？
- 是否跳转第三方平台完成交易？
- 是否提供付费内容、下载、订阅或预约？
- 是否站内生成订单、收款或交付？
- 是否允许第三方商家入驻？

尽量保存书面回复、工单编号、咨询日期和网站截图。

## 推荐路线

- 纯验证期：保持网站为作品和内容展示，交易放在规则清晰的第三方平台，并核验导流与广告属性。
- 稳定接单或变现：注册合适主体，按实际业务调整域名主办者与备案。
- 站内交易：使用 [[个人站点商业化迁移路线]]，完成主体、备案、支付、消费者和税务闭环。
