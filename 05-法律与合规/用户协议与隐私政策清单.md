# 用户协议与隐私政策清单

## 用户协议

- [ ] 经营者名称、地址与联系方式
- [ ] 服务内容、适用人群与账号规则
- [ ] 价格、税费、订阅、续费和取消
- [ ] 交付、退款和消费者权利
- [ ] 用户内容许可与禁止行为
- [ ] 知识产权与反馈
- [ ] AI 输出限制、用户责任与高风险用途
- [ ] 暂停、终止和数据处理
- [ ] 责任限制（不得排除强制性责任）
- [ ] 适用法律、争议与语言版本
- [ ] 变更通知与生效日期

## 隐私政策

- [ ] 谁是个人信息处理者/控制者
- [ ] 收集的数据类别、来源、目的和依据
- [ ] Cookie、分析和广告技术
- [ ] 支付、云、邮件、AI 等接收方
- [ ] 跨境传输和存储地区
- [ ] 保存期限或判断标准
- [ ] 安全措施和事件处理
- [ ] 查询、更正、导出、删除、撤回和投诉
- [ ] 儿童与未成年人
- [ ] 联系方式与更新历史

## 上线检查

- 政策必须与真实产品、SDK 和后台一致。
- 在收集数据前提供必要告知与同意。
- 保留用户接受的条款版本和时间。
- 重大变更不应只悄悄替换页面。
- 翻译版本要说明优先语言并保持同步。

条款不是万能免责。先完成 [[全球隐私与数据合规]] 或 [[中国互联网合规]] 的实际流程。
