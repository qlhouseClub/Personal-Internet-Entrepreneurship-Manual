# 广告合作审查：{{title}}

## 合作信息

- 广告主：
- 统一社会信用代码/身份：
- 地址和联系方式：
- 商品/服务：
- 合作模式：广告位 / 赞助 / 付费内容 / 联盟佣金 / 产品置换
- 投放时间：
- 费用、税费和发票：

## 资质与品类

- [ ] 广告主身份已核验
- [ ] 商品或服务可以合法生产、销售和宣传
- [ ] 所需行政许可有效
- [ ] 是否属于禁止互联网广告品类
- [ ] 是否属于广告发布前需审查品类
- [ ] 未成年人媒介限制已检查

## 内容

- [ ] 宣传主张有证据
- [ ] 价格、优惠、销量和效果真实
- [ ] 不使用绝对化、保证性或误导性表述
- [ ] 图片、音乐、字体、商标有权使用
- [ ] 体验和测评与真实经历一致
- [ ] 广告主修改意见未破坏真实性

## 可识别性与体验

- [ ] 显著标明“广告”
- [ ] 商业合作/佣金关系说明在点击前可见
- [ ] 原生广告不伪装成独立编辑内容
- [ ] 弹出广告可以一键关闭
- [ ] 不用虚假按钮或系统提示诱导点击

## 链接与数据

- [ ] 已核验最终落地页和下一级链接
- [ ] 追踪参数和 Cookie 已进入隐私评估
- [ ] 不向广告平台发送敏感数据
- [ ] 定期复查链接和商品内容

## 档案

- [ ] 合同、报价、发票和付款
- [ ] 营业执照、许可和审查证明
- [ ] 最终素材、页面截图和发布日期
- [ ] 修改记录、链接和投放记录
- [ ] 投诉、下架和整改
- [ ] 设定不少于三年的保存期限（按适用规则核验）

## 结论

允许 / 修改后允许 / 拒绝
