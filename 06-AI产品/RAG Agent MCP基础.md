# RAG、Agent 与 MCP 基础

## RAG

检索增强生成：先从知识源找到相关内容，再把证据交给模型生成。适合需要新鲜、私有或可引用知识的场景。

关键质量来自：文档权限、切分、检索、重排、引用和“找不到时拒答”，不只是向量数据库。

## Agent

Agent 让模型选择工具并执行多步任务。价值来自闭环完成工作，风险来自越权、循环、不可逆操作和外部内容注入。

高风险动作应：

- 使用最小权限；
- 在执行前展示影响；
- 要求人类确认；
- 支持幂等、撤销与审计；
- 限制步数、成本和时间。

## MCP

MCP 可用于标准化模型与工具、资源的连接。它降低集成摩擦，但不自动解决认证、授权、数据最小化和供应链信任。

## 何时不用复杂架构

- 固定流程可用普通代码可靠完成；
- 知识规模很小，可直接放入上下文；
- 输出不能验证、错误代价高；
- 用户需求尚未证明。

任何架构选择都应先通过 [[AI产品机会地图]] 和 [[AI安全评估与运营]]。
