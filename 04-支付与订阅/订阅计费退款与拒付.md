# 订阅、计费、退款与拒付

## 订阅状态

至少区分：

```text
试用 → 生效 → 付款失败/宽限期 → 暂停 → 取消 → 到期
                         ↘ 退款 / 拒付
```

权限不应只依赖支付页面跳转结果，而应依赖服务端的订阅状态。

## 定价模型

- 固定月费 / 年费；
- 按席位；
- 按用量；
- 点数包；
- 基础订阅 + 超额用量；
- 企业合同。

AI 产品优先用 [[大模型成本与定价]] 验证极端用量。

## 用户体验清单

- [ ] 价格、币种、税费和计费周期明确
- [ ] 试用结束与自动续费条件清楚
- [ ] 升降级、按比例计费规则明确
- [ ] 取消入口易找到
- [ ] 取消后的访问和数据保留规则明确
- [ ] 退款政策与当地强制性消费者权利不冲突
- [ ] 付款失败有提醒和合理重试

## 拒付证据包

- 订单、账单与支付记录；
- 用户同意订阅和条款的时间；
- 登录、使用和交付证据；
- 客服沟通、退款政策和取消记录；
- 风险检查结果。

高拒付通常是产品和预期管理问题，不只是支付问题。与 [[社区客服与留存]] 联动改进。
