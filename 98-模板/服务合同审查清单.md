# 服务合同审查：{{title}}

## 当事人

- [ ] 真实名称、证件/统一社会信用代码
- [ ] 地址、通知方式、签约授权
- [ ] 收款主体和开票主体一致

## 范围与协作

- [ ] 已附 [[服务项目范围说明书]]
- [ ] 交付物、格式、数量、非目标明确
- [ ] 客户资料、账号和反馈义务明确
- [ ] 里程碑和排期顺延机制明确
- [ ] 修改轮次和变更单机制明确

## 验收

- [ ] 可观察的验收标准
- [ ] 验收人和反馈期限
- [ ] 不合格时的修正/重作
- [ ] 沉默处理方式合理且已显著说明

## 费用

- [ ] 总价、税费、发票和第三方成本
- [ ] 预付款、里程碑款和尾款
- [ ] “定金”使用准确且不超过法定范围
- [ ] 逾期付款、暂停和催收
- [ ] 取消后的已完成工作和预留产能结算

## 知识产权

- [ ] 转让或许可的具体权利、地域、期限和媒介
- [ ] 权利生效与付款条件
- [ ] 源文件、未采用方案和工作文件归属
- [ ] 作品集、署名和案例展示权
- [ ] 客户素材与第三方字体/图片/模板
- [ ] AI 参与、模型条款和输出风险

## 保密与数据

- [ ] 保密范围、例外和期限
- [ ] 个人信息和客户数据处理
- [ ] 分包商和第三方工具
- [ ] 项目结束后的返还/删除
- [ ] 数据事件通知

## 终止与责任

- [ ] 暂停、解除和补救期限
- [ ] 已交付但未付清时的使用限制
- [ ] 责任限制不排除强制性责任
- [ ] 适用法律和争议解决
- [ ] 不可抗力和通知
