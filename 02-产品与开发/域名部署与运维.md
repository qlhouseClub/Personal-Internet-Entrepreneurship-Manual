# 域名、部署与运维

## 域名与账户

- [ ] 域名由经营主体或明确的所有人持有
- [ ] 注册商、DNS、云服务均启用 MFA
- [ ] 恢复邮箱与手机号不是单点
- [ ] 开启自动续费并保存付款方式
- [ ] DNS 变更有记录，关键域名启用锁定

## 上线基础

- [ ] HTTPS 与证书自动更新
- [ ] 生产、测试环境分离
- [ ] 密钥不进入代码仓库
- [ ] 日志不记录密码、完整令牌或不必要的个人信息
- [ ] 数据库和文件有备份
- [ ] 已实际演练恢复，而不只是“开启备份”

## 可观察性

至少监控：

- 首页、注册、登录、核心任务、支付回调；
- 错误率、延迟、资源使用和队列积压；
- 邮件发送失败、支付失败和模型供应商异常；
- 数据备份是否完成。

## 事件处理

1. 发现与分级；
2. 限制影响；
3. 恢复服务；
4. 通知受影响用户或主管机构（如适用）；
5. 复盘并修复系统性原因。

中国大陆部署还需结合 [[中国互联网合规]]；供应商和数据流应记录在 [[全球隐私与数据合规]]。
