# 独立站电商上线清单

## 1. 主体与网站

- [ ] 已判断个人免登记例外、个体工商户或公司路径
- [ ] 主体经营范围与实际商品/服务相符
- [ ] 特定商品、服务和行业许可已核验
- [ ] 域名实名、主办者、备案和实际经营主体一致
- [ ] 首页持续公示营业执照、行政许可或依法无需登记的信息
- [ ] 已向属地通信管理局或接入商核验 ICP/EDI 等问题

## 2. 商品与服务

- [ ] 每项商品完成 [[电商商品合规卡]]
- [ ] 名称、规格、材质、功能、限制和适用人群真实
- [ ] 价格、促销、库存和交付时间无误导
- [ ] 图片、字体、商标和描述拥有权利
- [ ] 定制品的需求确认、打样和允许偏差明确
- [ ] 数字商品的授权范围、设备数、更新和交付方式明确

## 3. 订单与合同

- [ ] 下单前可核对和更正输入
- [ ] 运费、税费、服务费和总价在付款前显示
- [ ] 订单成功、合同成立和库存失败逻辑清楚
- [ ] 订单页面可下载或保存
- [ ] 商品页面和交易政策按版本留档
- [ ] 电子签名、点击同意和日志可证明

## 4. 支付与发票

- [ ] 商户主体与结算账户一致
- [ ] 服务端验证支付结果，回调幂等
- [ ] 实测支付失败、重复支付、退款和关闭订单
- [ ] 发票、收据或服务凭证流程明确
- [ ] 订单—支付—银行—发票—账簿可以对账

## 5. 交付与售后

- [ ] 实物的物流、签收、破损和丢件流程
- [ ] 数字商品的下载、授权和交付证据
- [ ] 服务的里程碑、验收和修改流程
- [ ] 七日无理由退货适用范围逐项判断
- [ ] 不适用情形在购买必经流程中依法标注/确认
- [ ] 质量问题、退款、投诉和争议入口可用

## 6. 订阅和会员

- [ ] 首次价格、优惠期、正常续费价和周期明确
- [ ] 接受服务前显著提示自动续费
- [ ] 续费日前按规则再次显著提醒
- [ ] 提供显著、简便的取消或变更入口
- [ ] 取消后的访问、数据、退款和恢复规则明确

## 7. 隐私与安全

- [ ] 地址、电话和身份证等数据只在必要时收集
- [ ] 支付、物流、客服、分析和邮件供应商已披露
- [ ] 管理员 MFA、最小权限和操作日志
- [ ] 订单数据的保存期限和删除规则
- [ ] 数据查询、更正、删除和账号注销已测试
- [ ] 备份、恢复和数据事件响应已演练

## 8. 广告与营销

- [ ] 自有宣传真实，不虚构效果、销量和评价
- [ ] 付费测评、佣金链接和赞助显著标明广告
- [ ] 弹出广告可以一键关闭
- [ ] 禁止和需审查的广告品类已排除或取得审查
- [ ] 营销邮件、短信和即时通讯尊重同意与拒绝

## 9. 上线证据包

- [ ] 主体、备案、许可和支付审批文件
- [ ] 商品合规、供应商和权利文件
- [ ] 条款、隐私、退货和订阅政策版本
- [ ] 关键用户旅程测试记录
- [ ] 广告、订单、交付、退款和投诉记录方案
- [ ] 专业意见和主管部门咨询记录

将红色阻塞项同步到 [[05合规与上线检查]]。
