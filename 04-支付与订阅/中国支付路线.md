# 中国支付路线

## 路线

- 第三方内容或电商平台内收款；
- 个人阶段的合规线下服务结算；
- 个体工商户或公司申请微信支付、支付宝等商户；
- 通过小程序、网站、App 或线下码等具体产品接入。

不同产品形态、经营类目和商户主体所需材料不同，必须在支付机构官方商户平台核验。

## 接入前

- [ ] 经营主体、经营范围和产品实际内容一致
- [ ] 网站/App/小程序的备案或许可情况已评估
- [ ] 商品、服务描述和退款规则清晰
- [ ] 商户名称、结算账户和发票流程一致
- [ ] 禁限售和高风险业务已核验
- [ ] 隐私政策说明支付所需的数据共享

## 产品流程

```text
创建订单 → 调起支付 → 服务端验证结果 → 交付
→ 开票/凭证 → 退款/售后 → 对账
```

不要只相信前端“支付成功”页面；服务端应验证平台通知并处理重复通知。

## 经营提醒

- 个人收款码不应替代应使用的商户经营收款。
- 支付接入不等于业务本身已经满足备案、许可、消费者保护或税务要求。
- 会员自动续费、价格展示、取消和退款应清楚且可操作。
