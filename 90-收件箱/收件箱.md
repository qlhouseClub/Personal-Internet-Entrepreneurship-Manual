# 收件箱

把尚未判断价值或归属的信息暂时放在这里。每周清理一次。

## 待处理

- [ ] 示例：某支付平台的新政策 → 核验官方来源 → 更新 [[国际支付路线]]
- [ ] 示例：一个竞品的定价页 → 使用 [[案例研究]] → 链接到 [[案例库索引]]
- [ ] 示例：一个业务选择 → 使用 [[决策记录]] → 加入 [[决策记录索引]]

## 清理规则

每条信息只能有四种去向：

1. 删除：不再有价值。
2. 行动：进入项目任务或日程。
3. 参考：进入已有主题笔记并附来源。
4. 新笔记：有独立复用价值，建立链接后再移走。
