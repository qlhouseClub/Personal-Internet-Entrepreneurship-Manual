# 05 合规与上线检查

参考：[[合规总览与风险分级]]。

## 红色停止线

- [ ] 主体和所需许可已确认
- [ ] 无明显违法或平台禁止业务
- [ ] 高风险数据和 AI 使用有合法路径
- [ ] 无无法控制的严重安全风险
- [ ] 消费者能看清价格、续费、取消和退款

任一项不能确认时暂停公开上线。

## 产品与合同

- [ ] 经营者信息清楚
- [ ] 用户协议与隐私政策符合真实功能
- [ ] 条款版本与用户接受记录
- [ ] 支付、订阅、退款和取消已测试
- [ ] 客服与投诉渠道可用

## 数据与安全

- [ ] 数据清单、目的、依据与保存期
- [ ] Cookie/SDK 与告知同意一致
- [ ] 供应商和跨境数据已评估
- [ ] 导出、更正、删除和撤回流程已测试
- [ ] 备份、告警和事件流程已演练

## 内容与 AI

- [ ] UGC 规则、举报、处置与申诉
- [ ] AI 能力边界、标识和高风险用途限制
- [ ] 模型、提示词和评估版本可追踪
- [ ] 有害输出、提示注入和越权测试
- [ ] 知识产权和数据来源可说明
