# 风险与阶段门

## 阶段 0：问题

**通过条件：**

- [ ] 能说出一个具体用户和具体场景
- [ ] 至少 5 次高质量访谈或等价行为证据
- [ ] 用户已有替代方案、预算或明显损失

未通过时，不注册昂贵主体，不做完整产品。参见 [[用户研究与需求验证]]。

## 阶段 1：方案

**通过条件：**

- [ ] 用户能理解价值主张
- [ ] 原型或人工服务可交付核心结果
- [ ] 有预约、试用、预付或明确采购意愿

未通过时，缩小 [[从问题到MVP|MVP]]。

## 阶段 2：可经营性

**通过条件：**

- [ ] 有可行的主体与收款路线
- [ ] 成本、税务和退款不会摧毁毛利
- [ ] 合规风险有负责人和处理方案
- [ ] 供应商条款允许当前业务

使用 [[03主体与支付决策]] 和 [[05合规与上线检查]]。

## 阶段 3：发布

**通过条件：**

- [ ] 监控、备份、客服和退款流程已演练
- [ ] 条款、隐私与必要同意已上线
- [ ] 关键用户旅程可完成
- [ ] 已定义停止线和回滚方案

## 阶段 4：扩张

**通过条件：**

- [ ] 留存和复购不是偶然
- [ ] 单位经济模型为正或有可信改善路径
- [ ] 每月结账、申报和供应商管理可持续
- [ ] 新国家、新渠道或新功能经过单独风险评估

## 三类停止线

- **法律停止线**：缺必要许可、不能合法处理数据、无法履行消费者义务。
- **财务停止线**：贡献毛利持续为负、现金低于安全阈值、拒付率异常。
- **产品停止线**：关键结果不可重复、严重安全问题、用户损害不可接受。
