# 获客渠道地图

| 渠道 | 适合 | 优点 | 风险 |
|---|---|---|---|
| 创始人销售 | 早期 B2B、高客单 | 学习快、反馈深 | 难规模化 |
| SEO / 内容 | 有稳定搜索需求 | 复利、信任 | 起效慢、算法变化 |
| 社区 | 垂直人群、开发者、兴趣群 | 真实对话 | 反推广规则 |
| 产品驱动 | 可协作、分享、邀请 | 低边际成本 | 需要产品机制 |
| 伙伴/联盟 | 互补产品与服务商 | 借用信任 | 归因、佣金和合规 |
| 付费广告 | 已验证转化和 LTV | 可控扩量 | 烧钱、平台依赖 |
| 市场/应用商店 | 插件、模板、应用 | 内置发现 | 抽成和规则 |
| 邮件 | 已有许可名单 | 自有渠道、可自动化 | 同意、投递率 |

## 选渠道

先回答：

- 用户已经在哪里寻找解决方案？
- 你能持续生产什么独特资产？
- 渠道反馈周期多长，是否符合现金跑道？
- 是否能独立追踪“触达 → 激活 → 付费 → 留存”？

## 90 天原则

选择一个主渠道、一个辅助渠道：

1. 定义理想客户；
2. 建立可重复内容或触达节奏；
3. 每周记录投入、线索、激活、付费和留存；
4. 运行至少一个完整反馈周期再判断。

不要只看点击和注册；与 [[SaaS单位经济模型]] 联动看 CAC 与回收期。
