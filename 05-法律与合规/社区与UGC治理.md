# 社区与 UGC 治理

有评论、发帖、上传、私信或公开分享，就要把内容治理视为核心产品系统。

## 治理闭环

```text
规则 → 预防 → 发现 → 分级 → 处置 → 通知
→ 申诉 → 复盘 → 规则/产品更新
```

## 基础能力

- 社区规则和禁止内容；
- 举报入口、举报类别与证据；
- 自动检测与人工审核；
- 删除、限流、警告、暂停、封禁等分级措施；
- 用户申诉与复核；
- 执法请求和紧急风险流程；
- 审核员权限、培训与心理支持；
- 透明度和指标。

## 高风险类别

- 未成年人和性剥削内容；
- 自伤、自杀、暴力和可信威胁；
- 欺诈、冒充与隐私泄露；
- 仇恨、骚扰和网络暴力；
- 侵权内容与权利通知；
- 非法交易与受监管商品；
- AI 生成的欺骗性或有害内容。

## 设计问题

- 用户是否可匿名？平台内部是否需要可追溯身份？
- 私信和封闭群组如何举报？
- 被封禁用户如何申诉和取回数据？
- 哪些内容需要立即升级人工或外部机构？
- 记录保存多久，谁能访问？

中国场景还需结合 [[中国互联网合规]]；国际场景也需按用户所在地的法律与平台责任制度核验。
