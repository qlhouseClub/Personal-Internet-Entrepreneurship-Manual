# 商业模式地图

| 模式 | 典型收入 | 优势 | 主要难点 |
|---|---|---|---|
| 内容 | 订阅、广告、赞助、课程 | 启动轻、验证快 | 持续产出、广告合规与渠道依赖 |
| 软件 / SaaS | 订阅、席位、用量、增值功能 | 可规模化、经常性收入 | 开发、支持、流失 |
| AI 产品 | 订阅、点数、用量、企业合同 | 新场景与高杠杆 | 模型成本、可靠性、合规 |
| 数字产品 | 模板、资料、插件、授权 | 一次制作、多次销售 | 盗版、平台政策、复购 |
| 社区 | 会员、活动、招聘、赞助 | 网络效应与留存 | 内容治理与冷启动 |
| 服务 | 咨询、设计、开发、代运营 | 最快产生现金 | 范围、验收、应收款与知识产权 |
| 数据 / API | 订阅、调用量、数据授权 | 高复用、高切换成本 | 数据来源、准确性与权利 |
| 电商 | 实物、数字商品、定制与订阅 | 市场成熟 | 主体、备案、商品、物流与消费者保护 |

## 选择问题

1. 价值是持续发生，还是一次性交付？
2. 成本随用量增长吗？如果是，优先考虑用量或点数定价。
3. 用户是个人、小团队还是企业？购买流程完全不同。
4. 是否涉及用户发布内容、敏感数据、受监管行业或高风险 AI？
5. 你愿意承担客服、退款、社区治理和交付的哪部分工作？

## 组合策略

个人创业常用的低风险组合：

- 服务发现需求 → 工具化重复步骤 → SaaS 化。
- 免费内容建立信任 → 数字产品验证付费 → 订阅形成持续收入。
- 免费工具获客 → 高级功能收费 → 企业版增加权限和支持。
