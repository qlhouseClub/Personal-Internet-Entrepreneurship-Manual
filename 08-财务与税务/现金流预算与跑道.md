# 现金流预算与跑道

## 13 周现金表

| 周 | 期初现金 | 收入 | 固定支出 | 可变支出 | 税费/年费 | 期末现金 |
|---:|---:|---:|---:|---:|---:|---:|
| 1 |  |  |  |  |  |  |

短期用 13 周滚动预测，长期用 12 个月三情景预算。

## 三种情景

- 保守：收入延迟、退款上升、开户或结算受阻；
- 基准：按已验证转化和留存；
- 乐观：增长加速，但同时增加模型、客服和税费。

## 现金陷阱

- 年付收入被提前花掉；
- 支付平台准备金或冻结；
- 年度税务、审计、秘书和注册代理集中到期；
- 汇率波动；
- 模型成本在月底集中入账；
- 公司与个人资金混用；
- 关闭公司仍需额外费用。

## 跑道

```text
粗略跑道（月）= 可用现金 / 平均月净消耗
```

如果收入和成本波动大，不用单一平均值；按保守情景设置行动阈值。
