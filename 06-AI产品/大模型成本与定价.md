# 大模型成本与定价

## 单次任务成本

```text
模型输入 + 模型输出 + 嵌入/重排 + 搜索/工具
+ 存储与带宽 + 重试失败 + 人工复核 + 支付费
```

不能只用“每百万 Token 价格”估算。

## 场景表

| 场景 | P50 成本 | P95 成本 | 用户价值 | 失败成本 | 价格/额度 |
|---|---:|---:|---:|---:|---:|
|  |  |  |  |  |  |

P95 比平均值更重要，因为极端长输入、循环 Agent 和滥用会吃掉毛利。

## 成本控制

- 按任务选择模型，而非所有请求都用最大模型；
- 限制输入长度、工具次数和 Agent 步数；
- 缓存可复用结果；
- 先检索/分类，再调用昂贵生成；
- 超时、重试与并发设上限；
- 对高成本功能用点数、额度或用量计费；
- 监控每用户、每工作区和每功能成本。

## 定价检查

- 目标贡献毛利是否覆盖支持、退款和异常用量？
- 年付折扣是否会在使用高峰制造现金错觉？
- 免费试用是否容易被批量滥用？
- 企业用户是否需要席位、用量和服务等级组合？
