# 年度维护成本模型

## 总成本公式

```text
首年现金需求 =
成立成本 + 年度固定成本 + 交易成本 + 产品成本
+ 专业服务 + 税费准备金 + 意外缓冲 + 关闭准备金
```

## 三档预算

- **生存档**：仅保留法律义务与核心交付。
- **正常档**：包含可持续的会计、监控、客服和备份。
- **增长档**：增加营销、冗余、专业支持和团队成本。

## 比较主体时

统一使用：

- 同一币种和同一汇率日期；
- 相同的业务量、客户地和人员安排；
- 服务商含税报价与官方费用分列；
- 将创始人时间按机会成本计入；
- 估算“零收入一年”和“关闭公司”两种情景。

## 决策阈值

- 固定维护成本不应迫使你在需求未验证时仓促收费。
- 预留至少一个完整申报周期的现金。
- 模型成本和支付费应进入每单贡献毛利，参见 [[SaaS单位经济模型]]。
