# 账号、权限与数据

## 身份与认证

- 支持强密码、MFA 或可靠的第三方登录。
- 恢复账号时不要只依赖容易被接管的单一渠道。
- 管理员账号与普通账号分离，管理员强制 MFA。
- 登录、权限变更、导出和删除保留安全审计记录。

## 授权模型

先定义资源与动作：

| 角色 | 查看 | 创建 | 编辑 | 删除 | 管理成员 | 账单 |
|---|---|---|---|---|---|---|
| 所有者 |  |  |  |  |  |  |
| 管理员 |  |  |  |  |  |  |
| 成员 |  |  |  |  |  |  |
| 访客 |  |  |  |  |  |  |

服务端必须校验权限，不能只隐藏前端按钮。

## 数据生命周期

```text
收集 → 使用 → 共享/处理 → 保存 → 导出 → 删除/匿名化
```

对每类数据记录：

- 目的与必要性；
- 法律或合同依据；
- 保存期限；
- 存储地区与供应商；
- 谁能访问；
- 用户如何查询、更正、导出和删除。

## 最小化原则

没有明确用途的数据不要先收集。删除流程要覆盖主数据库、文件、搜索索引、分析系统和合理期限后的备份。
