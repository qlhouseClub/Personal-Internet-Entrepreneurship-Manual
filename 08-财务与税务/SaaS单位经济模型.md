# SaaS 单位经济模型

## 每客户每月

```text
净收入
- 支付与平台费
- 模型/API/托管可变成本
- 客服与人工交付
- 退款、拒付与欺诈损失
- 可归属税费
= 贡献毛利
```

## 核心公式

- 毛利率 =（收入 - 销售成本）/ 收入
- CAC = 获客相关投入 / 新增付费客户
- 粗略 LTV = 每客户月贡献毛利 / 月客户流失率
- CAC 回收期 = CAC / 每客户月贡献毛利

公式是简化模型；用户群、扩张收入、年付和小样本会扭曲结果。

## 分群

至少按以下维度分开看：

- 自助个人、团队、企业；
- 月付、年付；
- 获客渠道；
- 地区与币种；
- 产品计划；
- 首月、成熟期。

## 健康信号

- 贡献毛利为正且稳定；
- 留存改善不依赖持续人工补贴；
- CAC 回收期适合现金跑道；
- 高用量用户仍有合理毛利；
- 退款和拒付原因可控。
