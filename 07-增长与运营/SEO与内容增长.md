# SEO 与内容增长

## 从问题而非关键词开始

内容应覆盖用户旅程：

- 认识问题；
- 比较解决方法；
- 选择工具；
- 实施；
- 排错与进阶；
- 评估购买和迁移。

## 内容单元

每篇内容至少有：

- 明确读者与搜索/阅读意图；
- 独特经验、数据、案例或工具；
- 可执行步骤；
- 与产品价值自然连接的下一步；
- 作者、日期、更新和来源。

## 主题集群

```text
核心主题页
 ├─ 入门解释
 ├─ 操作指南
 ├─ 对比与替代
 ├─ 案例
 └─ 工具/模板
```

## 技术基础

- 页面可抓取、可索引；
- 标题、描述、规范链接和站点地图正确；
- 移动体验、性能与结构化信息合理；
- 404、重定向和重复页面受控；
- 多语言页面说明语言与地区关系。

## 指标

排名和流量只是中间指标。继续看高意向访问、注册、激活、付费、内容辅助转化和留存。
