# 合规总览与风险分级

## 七层合规地图

1. **主体与许可**：谁经营，是否需备案或许可。
2. **合同与消费者**：价格、订阅、退款、责任与争议。
3. **隐私与数据**：收集、使用、共享、跨境、删除与安全。
4. **内容与社区**：UGC、举报、未成年人和违法有害内容。
5. **知识产权**：品牌、代码、素材、训练数据和输出。
6. **AI 与自动化**：风险分类、透明度、人类监督与评估。
7. **行业规则**：医疗、教育、金融、就业、儿童等高风险领域。

## 风险分级

| 等级 | 例子 | 处理 |
|---|---|---|
| 红色 | 明显缺必要许可；处理高度敏感数据却无合法路径；高风险决策无人监督 | 暂停上线，取得专业意见 |
| 橙色 | 跨境数据、儿童用户、UGC、自动续费、AI 高影响场景 | 上线前专项评估与控制 |
| 黄色 | 一般个人信息、第三方分析、营销邮件、常规 B2C 条款 | 完成清单、记录和测试 |
| 绿色 | 不收集用户数据的静态展示或内部原型 | 保持最小化，定期复核 |

## 触发专项审查的问题

- 是否面向儿童或可能吸引儿童？
- 是否处理健康、金融、生物识别、精确位置等敏感数据？
- 是否允许发帖、私信、上传文件或公开分享？
- 是否自动决定就业、信贷、教育、医疗或重要权益？
- 是否跨境传输个人信息？
- 是否自动续费、提供数字内容或面向消费者？
- 是否使用未经确认权利的内容、代码或数据？
