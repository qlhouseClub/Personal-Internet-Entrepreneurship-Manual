# 个人创业财务基础

## 三张最小报表

- **利润表**：一段时间赚了还是亏了。
- **资产负债表**：某个时点拥有什么、欠什么、净值多少。
- **现金流**：现金为什么增加或减少。

利润不等于现金。年付订阅可能先收到现金，但收入确认和未来服务义务需单独理解。

## 分离个人与业务

- 独立银行/支付账户；
- 每笔个人投入、借款、报销和分配有性质；
- 保存合同、发票、收据和平台账单；
- 不用收入数字代替可提取利润。

## 月度结账

- [ ] 导出订单、支付、退款和银行
- [ ] 完成对账
- [ ] 记录收入、直接成本和经营费用
- [ ] 估计税费与未支付义务
- [ ] 核对订阅递延和预付
- [ ] 更新现金跑道与应收应付
- [ ] 保存月度快照并锁定来源文件

## 关键指标

- 收入与经常性收入；
- 毛利与贡献毛利；
- 现金余额与净消耗；
- 退款、拒付和坏账；
- 应收、应付与税费准备；
- 创始人实际工时与机会成本。
