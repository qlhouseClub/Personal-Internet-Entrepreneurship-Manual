# 指标、实验与复盘

## 指标树

```text
可持续价值
├─ 获客：合格访问/线索
├─ 激活：首次核心结果
├─ 留存：周期重复价值
├─ 收入：付费、扩张、流失
└─ 质量：错误、工单、退款、风险事件
```

## 北极星指标

优先衡量“用户获得的价值单元”，例如完成并被接受的报告、成功自动化的任务，而不是登录次数。

## 实验要求

- 明确用户问题与假设；
- 一个主要指标和护栏指标；
- 写出基线、目标、样本和周期；
- 预先定义成功、失败和继续条件；
- 记录副作用与不同用户群差异；
- 结束后做决策，不只做报告。

使用 [[实验卡]]。

## 每周复盘

1. 哪个数字变化最大，为什么？
2. 哪个用户行为反驳了我们的假设？
3. 收入、成本、风险是否被同一个变化影响？
4. 下周只做哪一个最重要实验？

结果同步到 [[07经营仪表盘]]、[[SaaS单位经济模型]]。
