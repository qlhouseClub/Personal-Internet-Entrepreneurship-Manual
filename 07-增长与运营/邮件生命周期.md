# 邮件生命周期

## 邮件类型

- 交易邮件：验证、收据、安全通知、重置密码。
- 产品邮件：新手引导、任务提醒、使用报告。
- 营销邮件：内容、促销、活动、召回。

不同类型的法律依据、退订要求和发送优先级可能不同，不要混在一个无差别名单中。

## 生命周期

```text
订阅/注册 → 欢迎 → 激活 → 价值提醒 → 转化
→ 留存 → 流失预警 → 召回 → 退订/删除
```

## 基础清单

- [ ] 记录来源、同意和政策版本
- [ ] 营销邮件有清晰退订
- [ ] 退订及时生效并跨系统同步
- [ ] 域名认证与发信信誉配置
- [ ] 不向购买或抓取的名单群发
- [ ] 模板包含真实发件人信息
- [ ] 频率和时区符合用户预期
- [ ] 交易邮件不因营销退订而丢失

## 指标

送达、退信、投诉、退订、点击只是基础；真正看激活、首次价值、付费、留存和支持负担。
