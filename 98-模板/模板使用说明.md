# 模板使用说明

- [[服务项目范围说明书]]
- [[服务合同审查清单]]
- [[广告合作审查单]]

## 使用方法

1. 新建一个空白笔记。
2. 打开命令面板，选择“插入模板”。
3. 选择合适模板。
4. 修改标题、属性、链接和日期。

模板本身保留在 `98-模板`，不要直接把项目内容写在模板文件中。
